# Technician Dashboard Workflow

The standard Dashboard remains WAID's simple home experience. Technician Dashboard is an optional local presentation profile, not an authorization role: it grants no additional privileges and cannot bypass repair approval, policy, elevation, audit, or recovery controls.

Use Refresh to compose recent real scan findings, persisted repair workflows, immutable repair evidence, and locally stored cases. Compact and Detailed layouts plus the saved filter are presentation preferences. Case IDs, titles, and notes are stored separately from scan and repair evidence. Input lengths are bounded, and no personal file contents are collected.

A typical workflow is: review system overview, filter active incidents, inspect evidence and recent changes, associate local case notes, open the existing repair workflow for approval, then use History or Monitoring & Reports for redacted exports. Large result sets are capped at 500 incidents, 500 audit entries, 100 repair workflows, and 500 cases to preserve responsiveness.

Keyboard operation uses native WinUI controls. Real-device keyboard, Narrator, high-contrast, scaling, and long-running multi-incident validation remain part of the manual Windows matrix.
